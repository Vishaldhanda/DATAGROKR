# Week 1 Mini Project - CLI Grade Calculator

## Description

A command-line based Grade Calculator developed using Python.

The program takes student details and marks for multiple subjects as user input. It calculates the total marks, average marks, and assigns a grade based on the average.

## Features

- User input for student name
- User input for number of subjects
- User input for subject names and marks
- Total marks calculation
- Average calculation
- Automatic grade calculation
- Input validation
- Exception handling
- Option to calculate results for multiple students

## Technologies Used

- Python
- Functions
- Loops
- Dictionaries
- Conditional statements
- Exception handling
