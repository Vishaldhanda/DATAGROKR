# SQL E-commerce Report - Week 4

MySQL e-commerce database mini-project with 40+ SQL queries covering NULL handling, aggregates, GROUP BY, HAVING, JOINs, CASE, string/date functions, subqueries, window functions, ROLLUP, GROUPING SETS, views, DDL and constraints.

## Files
- ecommerce_schema.sql
- ecommerce_data.sql
- ecommerce_queries.sql
- README.md
- .gitignore

## Run in MySQL Workbench
1. Open MySQL Workbench.
2. Run `ecommerce_schema.sql`.
3. Run `ecommerce_data.sql`.
4. Run `ecommerce_queries.sql`.

## Tables
customers, products, orders, order_items, reviews
